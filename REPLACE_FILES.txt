LinOx Mobile 1.0.0 FIXED
========================

This archive is a full replacement project based on the supplied Linux_Mobile-main snapshot.

Important fixed files/features:
- .github/workflows/android.yml
- app/src/main/AndroidManifest.xml
- app/src/main/res/layout/activity_main.xml
- app/src/main/java/org/linox/mobile/LinuxRuntime.kt
- app/src/main/java/org/linox/mobile/DistroManager.kt
- app/src/main/java/org/linox/mobile/DistroActivity.kt
- app/src/main/java/org/linox/mobile/TerminalActivity.kt
- app/src/main/java/org/linox/mobile/MainActivity.kt
- app/src/main/cpp/pty_bridge.cpp
- app/src/main/assets/proot-aarch64-static

Build:
- JDK 17
- AGP 8.5.2 / Kotlin 1.9.24
- Gradle 8.9 generated by CI
- compileSdk 35
- NDK 27.0.12077973
- CMake 3.22.1
- no deprecated ndk.dir in local.properties

Runtime:
- Bundled user-supplied AArch64 PRoot v5.3.0 is installed automatically on first run.
- PRoot can still be replaced from the UI.
- MainActivity is the launcher.
- Linux setup is visible from the main screen.
- Ubuntu 24.04 LTS quick install plus Debian 13, Alpine 3.22, Fedora 42,
  Arch Linux, Kali Rolling, Rocky Linux 10 and openSUSE Leap.
- Docker/OCI ARM64 manifest selection, SHA-256 layer verification, gzip/zstd extraction.
- Persistent rootfs activation.
- Interactive PTY terminal and command execution through PRoot.
- PTY host cwd bug fixed: the native bridge now receives the real Android app
  home path while PRoot maps it to guest /root.
- DNS configuration and host-network reuse for Linux userspace.

The APK will not contain every distro rootfs because that would make the APK huge.
Use the Linux screen to download the distro you want; Ubuntu is the recommended first install.
